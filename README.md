# Pie Square Premium Scroll Website

A static premium scroll-driven prototype for Pie Square Technologies, built from the 2026 company profile.

# Pie-Square-Technologies-

## Run

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Structure

- `index.html` - content and page structure
- `styles.css` - complete visual system and responsive layout
- `script.js` - scroll choreography, sticky scenes, parallax, progress and project rail
- `assets/` - imagery cropped from the provided company profile for prototyping

## Production upgrade path

For a production/Awwwards-oriented build, port this concept to Next.js and replace selected prototype visuals with high-resolution original project photography / purpose-built 3D assets. GSAP ScrollTrigger and optional WebGL can then be introduced for more granular motion control.
